MAUT AI — БЕСПЛАТНАЯ ЛОКАЛЬНАЯ ВЕРСИЯ

ВАЖНО: OpenAI API-ключ и оплата не нужны. Ответы создаёт модель на вашем компьютере через Ollama.

ПЕРВЫЙ ЗАПУСК
1. Установите Ollama: https://ollama.com/download/windows
2. После установки откройте эту папку снова, если она была открыта.
3. Дважды нажмите INSTALL-LOCAL-MODEL.bat и дождитесь завершения загрузки Qwen 2.5 3B (несколько ГБ).
4. Дважды нажмите START-MAUT-AI.bat. На первом запуске он установит зависимости приложения.
5. Сайт откроется на http://localhost:3000. Зарегистрируйтесь/войдите и пишите сообщения.

Требуется Windows 10/11, Node.js LTS и интернет для первичной загрузки. Ollama работает локально; скорость зависит от компьютера. Для 8 ГБ ОЗУ выбрана компактная модель Qwen 2.5 3B.

Если Ollama не найдена, закройте и снова откройте START-MAUT-AI.bat после установки. Не удаляйте папку data, если хотите сохранить локальные аккаунты.

Эта версия поддерживает текстовый чат. Создание изображений отключено, поскольку оно в исходном проекте использовало платный OpenAI API.
