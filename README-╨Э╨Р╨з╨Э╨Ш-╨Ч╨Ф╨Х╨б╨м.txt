MAUT AI — БЕСПЛАТНЫЙ ЛОКАЛЬНЫЙ ИИ НА WINDOWS

1. Установи Ollama: https://ollama.com/download/windows
2. Установи Node.js LTS, если ещё не установлен: https://nodejs.org/
3. Дважды нажми INSTALL-LOCAL-MODEL.bat и дождись загрузки модели Qwen 2.5 3B (несколько ГБ).
4. Дважды нажми START-MAUT-AI.bat.
5. Сайт откроется в браузере: http://localhost:3000
6. Создай аккаунт и пиши сообщения ИИ.

ВАЖНО:
- API-ключ OpenAI и оплата не нужны.
- Первый запуск требует интернета, чтобы скачать модель и зависимости.
- Чёрное окно должно оставаться открытым, пока пользуешься сайтом.
- Эта версия поддерживает текстовый чат; создание изображений пока отключено.
- Если появится ошибка, сфотографируй чёрное окно и покажи её.
