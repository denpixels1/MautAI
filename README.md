# Maut AI — бесплатная локальная версия

Эта версия заменяет платный OpenAI API на локальную модель через Ollama. OpenAI API key и API billing не нужны.

## Windows: самый простой запуск
1. Установите Ollama: https://ollama.com/download/windows
2. Убедитесь, что Node.js LTS установлен: https://nodejs.org/
3. Дважды нажмите `INSTALL-LOCAL-MODEL.bat`. Скрипт скачает `qwen2.5:3b` (несколько ГБ). Это нужно сделать один раз.
4. Дважды нажмите `START-MAUT-AI.bat`. Он установит npm-зависимости и запустит сервер.
5. Откройте `http://localhost:3000`, зарегистрируйтесь и общайтесь.

## Требования
- Windows 10 22H2 или новее.
- Node.js LTS.
- Ollama for Windows.
- Интернет для установки и загрузки модели; затем генерация текста идёт локально.
- Рекомендуемая модель для 8 ГБ ОЗУ без NVIDIA: `qwen2.5:3b`. На CPU ответы могут генерироваться медленно.

## Важно
- Не нужен `.env` с ключом OpenAI. Если `.env` отсутствует, launcher создаст его из `.env.example`.
- Локальная версия поддерживает текстовый чат. Генерация изображений отключена, так как исходная функция использовала OpenAI Images API.
- Не публикуйте сервер в интернете без дополнительной настройки безопасности.
